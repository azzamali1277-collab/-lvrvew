## 🎯 التخصيص | Customization

### تغيير الألوان
عدّل متغيرات CSS في `styles.css`:
```css
:root {
    --bg-beige: #f5f1ed;      /* لون الخلفية */
    --text-brown: #2C1810;    /* لون النصوص */
    --gold: #D4AF37;          /* لون الذهب */
}
```

### إضافة عناصر جديدة
اتبع نفس تنسيق العناصر الموجودة:
```html
<div class="menu-item">
    <div class="item-header">
        <h3 class="item-name">اسم المنتج</h3>
        <span class="item-price">السعر</span>
    </div>
</div>
```
